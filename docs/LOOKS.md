# Complete recording looks

These are ready-made combinations of camera response, noise, color bleed, tape stability, occasional defects and optional CRT playback. Browse them as complete pictures; the detailed controls are optional.

Start with **02** for clean DV, **03** for low-light gain, **06** for warm home video, **09** for found footage, **10** for a worn dub, **12** for monochrome security, **13** for noisy night surveillance, and **15** for home video on a TV.

Damaged presets demonstrate a first short defect after about 1.6 seconds, then use irregular quiet intervals. **Preview this look’s tape damage** plays the selected defect immediately. Enemy/explicit cues take priority. Reduced flashing suppresses the preset defects and tape noise; it is never switched off by browsing.

Camera names describe artistic AV-capture interpretations, not exact device or codec emulations. IR-style surveillance does not add infrared illumination. CRT-only looks do not receive tape defects.

Browsing preserves the current video budget and automatic world-resolution policy. Recurring-defect type, rate and strength are included with all other settings in captures. The library does not enable the receiver or supersampling.
